# Sauce Demo – Manual QA Practice Portfolio

This repository contains my practice work in manual software testing using the Sauce Demo website (https://www.saucedemo.com).

I used this project to practice:
- Writing clear test cases
- Executing tests and recording Pass/Fail results
- Finding and reporting bugs with proper steps to reproduce
- Working with different user accounts (especially `problem_user`)

This is part of my self-learning journey in Software Quality Assurance as I transition from a healthcare background into tech.
